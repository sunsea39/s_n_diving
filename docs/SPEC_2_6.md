# N×S_Diving 改修仕様 v2.6（小さな修正）

フロントエンドのみ。DB の変更なし。

## 1. 下部メニューの下の余白

- 症状：スマホの下部タブ（ホーム／資料／事故事例／掲示板）が画面の下端ぎりぎりに見える
- `.bottom-tabs` の下の余白を `calc(12px + env(safe-area-inset-bottom, 0px))` に（上は 6px）。ホームバーのある iPhone でも、ない Android でも、ラベルの下に 12px 以上の余白ができること
- タブの高さが増えた分、`main` とフッターの下余白（タブに隠れないための余白）も同じ値で更新（CSS 変数 `--tabbar-h` にまとめる）

## 2. 資料の「要点のみ」ボタン

- 文言：オフのとき **「要点のみに切り替え」**、オンのとき **「全文に切り替え」**（`aria-pressed` はそのまま）
- 見た目：資料詳細の **「PDF・印刷」ボタンと同じ形**（同じクラス・高さ・角丸・枠・文字サイズ）。オンのときは同じ形のまま、枠と文字を `--teal` にして状態がわかるように
- 置き場所：「PDF・印刷」ボタンの隣に並べる（スマホで入りきらなければ折り返し）。目次チップの列からは外す
- 印刷ページの設定バーの「要点のみ」（`PrintControls.tsx`）は変えない

## 3. 「▲ 上へ」ボタン

- **すべてのページ**で使えるようにする（今は資料詳細だけ）。`SiteLayout` に 1 つだけ置く。管理画面・印刷ページには出さない
- **少しでも下にスクロールしたら表示**（`scrollY > 8`）。一番上では非表示。フェード（管理画面はアニメなし）
- 位置：
  - スマホ（下部タブ表示時）：**右下の「掲示板」タブの真上あたり**。`right: 12px`、`bottom: calc(var(--tabbar-h) + 10px)`。幅は掲示板タブと中心がそろうよう、タブ 1 つ分の幅の中央に置く（`right` を `calc(12.5vw - 半分の幅)` で計算してよい）
  - PC：右下 `right: 24px; bottom: 24px`
- 形：丸型 48×48px、▲ のアイコン＋小さく「上へ」（読み上げ用に `aria-label="ページの先頭へ"`）。押したら `scrollTo({ top: 0, behavior: 'smooth' })`（reduced-motion は即時）
- ドロワーやベルのパネルが開いている間は隠す
