# N×S_Diving 改修仕様 v2.10 — ライセンスの選び方

フロントエンドのみ。DB の変更なし（`valid_licenses` の許可リストはそのまま使う）。

## 現状と問題

- マイページ「ダイビング経験」の編集で、ライセンスが **テキストエリア**（「団体｜ランク」を 1 行ずつ手入力）になっている（`src/pages/MyPage.tsx`）。入力の形式が分かりにくく、表記ゆれで保存時に DB の検証に落ちる

## 新しい選び方（タブ → タブ）

1. **団体のタブ**（横並びのセグメント。スマホで入りきらなければ横スクロール）：**BSAC ／ PADI ／ NAUI ／ SSI ／ その他**
   - 初期表示は、登録済みライセンスの最初の団体（無ければ BSAC）
2. 選んだ団体の **ランクのタブ**（チップのボタン群、折り返しあり）：
   - BSAC：オーシャンダイバー／スポーツダイバー／ダイブリーダー／アドバンスドダイバー／ファーストクラスダイバー／インストラクター
   - PADI：オープン・ウォーター・ダイバー／アドバンスド・オープン・ウォーター・ダイバー／レスキュー・ダイバー／マスター・スクーバ・ダイバー／ダイブマスター／インストラクター
   - NAUI：スクーバダイバー／アドバンスドスクーバダイバー／レスキュースクーバダイバー／マスタースクーバダイバー／ダイブマスター／インストラクター
   - SSI：オープンウォーターダイバー／アドバンスドアドベンチャラー／ストレス＆レスキュー／アドバンスドオープンウォーターダイバー／マスターダイバー／ダイブガイド／ダイブマスター／インストラクター
   - 文字列は **DB の `valid_licenses` と一字一句同じ**にする（`src/content/licenses.ts` に定数として置き、Vitest で `supabase/migrations/20260928000000_v2_2.sql` の許可リストと一致することを確認する）
   - **その他**：ランクのタブの代わりに、自由入力欄（60 字まで）＋「追加」ボタン
3. ランクのタブを押すと **保有ライセンスに追加**、もう一度押すと **外す**（`aria-pressed`。選択中はチップの選択中の色）
   - 複数の団体・複数のランクを持てる（合計 **5 件まで**。5 件のときは未選択のタブを押せず「ライセンスは5件まで登録できます」と表示）
4. タブの上に **「登録するライセンス」** の一覧（「BSAC スポーツダイバー ×」のような小さなタグ。× で外す）。0 件なら「まだ選んでいません」
5. 「保存」で今まで通り `licenses` を保存。キャンセルで元に戻す

## 表示

- 表示モード（編集していないとき）は、今の「BSAC スポーツダイバー、PADI …」のままでよい。団体ごとに小さなタグで並べると見やすい（任意）

## 品質

- Vitest：ランクの定数が DB の許可リストと一致すること、追加／削除／5 件上限／同じものの重複防止の判定
- `npm run lint`（警告 0）、`npx tsc -b`
