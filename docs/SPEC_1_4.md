## 3. PDF 保存・印刷（カード）

### 3-1. 方針

- **ブラウザの印刷機能で PDF を作る**（「PDF として保存」）。JS で画像化する方式は文字がぼやけ、日本語の検索もできないので使わない
- 資料詳細ページに「PDF・印刷」ボタン → 印刷専用ページ `/docs/:slug/print` を開く
- 印刷専用ページは **サイトのヘッダー・フッター・タブ・ドロワーを出さない**。画面上部に設定バー（印刷時は非表示）、その下に印刷プレビュー
- 印刷時は常にライト配色。`print-color-adjust: exact` で ●赤・●黄やバッジの色を残す

### 3-2. 設定バー

| 設定 | 選択肢 | 初期値 |
|---|---|---|
| 形式 | **カード** ／ 通し（全文） | カード |
| カードの大きさ（形式＝カードのとき） | **A6（はがき 105×148mm）** ／ A7（ポケット 74×105mm） | A6 |
| 用紙 | **A4 に並べて印刷（切り取り線つき）** ／ カードの大きさで 1 枚ずつ | A4 に並べる |
| 内容（ダイビング入門など、要点の区別がある資料） | **要点のみ** ／ 要点＋本文 | 要点のみ |

- 「印刷・PDF 保存」ボタン（`window.print()`）と「資料に戻る」
- 設定の下に一行の案内：「PDF にするときは、印刷画面の送信先で『PDF として保存』を選んでください。iPhone は共有 → プリント → プレビューを 2 本指で広げると PDF になります。」
- 設定は localStorage（`ns-print`）に保存

### 3-3. カードの作り方

1 枚のカード = 1 つのまとまり。

| ブロック | カードの単位と中身 |
|---|---|
| `signs` | 機材 1 つ = 1 枚：イラスト（小）、番号と機材名、サブタイトル、症状（●赤／●黄 ＋ 症状 ＋ 理由）、交換・点検の目安 |
| `heading` で区切られた範囲 | 見出し 1 つ = 1 枚。**要点のみ**：`callout`（3行まとめ・絶対に守るルール・注意）と `steps`、`checklist`。**要点＋本文**：それに `text`・`table`・`qa` を加える |
| `cards`（習慣など） | ブロック 1 つ = 1 枚（項目を並べる） |
| 先頭の `intro` | 表紙カード 1 枚：資料名、カテゴリ、intro、凡例（signs があれば）、N×S_Diving のロゴ |

- カードの共通レイアウト：
  - 上端：資料名（小さく、`--teal`）と N×S_Diving のロゴ（右）
  - 本文：見出し（太字 `--navy`）→ 中身
  - 下端：「目安です。取扱説明書・インストラクターの指示を優先」（7pt、`--muted`）
  - 角丸の枠（印刷時は 0.3mm のグレー線）
- **文字の自動調整**：カードに収まらないときは、文字サイズを 10pt から 0.5pt ずつ下げて収める（下限 A6：7pt、A7：6.5pt）。下限でも収まらなければ、カードを分けて「（続き）」を付ける。計測は描画後に JS で行う
- A4 に並べるとき：A6 は 2×2（4 枚）、A7 は 2×4（8 枚）。カードの間に 5mm の余白、四隅にトンボ（切り取り線の目印、0.2mm の線）
- カードの大きさで 1 枚ずつ：`@page { size: 105mm 148mm; margin: 0 }`（A7 は 74mm 105mm）
- 表と裏の両面印刷はしない（片面のみ）

### 3-4. 通し（全文）

- `@page { size: A4; margin: 14mm 12mm; }`
- 資料をそのまま縦に並べる（折りたたみはすべて開く、目次チップ・ボタン類は出さない）
- 見出しの直後でページが切れないように `break-after: avoid`、機材セクションや callout の途中で切れないよう `break-inside: avoid`
- 各ページ下に資料名とページ番号（CSS の `@page` の margin box が使えないブラウザもあるので、無理なら省略可）
- 末尾に disclaimer

### 3-5. そのほか

- 事故事例の詳細ページにも「PDF・印刷」（通しのみ、A4）。`/accidents/:slug/print`
- 印刷ページは `noindex` のまま
- 画像（イラスト PNG）は読み込み完了を待ってから文字の自動調整を行う
