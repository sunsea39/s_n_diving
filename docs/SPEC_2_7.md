## 1. トップの上部：イラストを背景にする（オーナー選択：案A、ダークは案Dの星を追加）

- 見本：https://claude.ai/artifact/G4438tDyoVduGuokSYCvQJ の案A（Claude 作成）
- 構成：トップのヒーロー（kicker・見出し・リード・ボタン）の **背景** として、**ヘッダーの直下から** 空＋海のイラストを敷く
  - **空**：ヒーローの高さいっぱいの背景。**海のイラスト（今の `HeroScene` の海の部分）は今と同じ高さ**（スマホ 150px 前後／600px 以上 200px／1024px 以上 240px）でヒーローの下端に置き、その上を空が埋める
  - 見出し・リード・ボタンは空の上に重ねる（左右の余白は今の本文と同じ）
  - NEXT DIVE のカードは今と同じく海の下端に少し重ねる
  - `HeroScene` の空の四角（`hs-sky`）と太陽は、背景側の空に置き換える（空と海の境目に継ぎ目が出ないこと。奥の波・手前の波・ブイ・魚・泡・光・海底は今のまま）
- **ライト（案A「澄んだ空」）**
  - 空：上から `#FFFFFF` → 70% で `#EEF5F6` → 水平線で `#DDEFF1` の縦グラデーション
  - 太陽：右寄り（右端から 16%）、水平線の少し上に直径 28px 程度の `#F3C969` の円
- **ダーク（案A の夜空＋案D の星）**
  - 空：上 `#0E1A22` → 水平線 `#16303D`
  - 月：太陽と同じ位置に三日月（`#E6EEF1` の円に、空の色の円を少しずらして重ねる）
  - **星**：案D の星 5 個（見本の 300×430 の座標 (40,40) (120,60) (200,30) (260,80) (90,110)、半径 1.1）を、ヒーローの幅・高さに対する割合で配置。幅が広い画面では同じ並びを左右に繰り返してよい。色 `#E6EEF1`
- **動き**（今と同じ仕組み：`motion.css` の変数、`IntersectionObserver` で画面外は停止、reduced-motion で停止）
  - 海：今の動き（波・泡・魚・光・ブイ）をそのまま
  - 星：ゆっくり瞬く（opacity 0.35 ↔ 1、3.5〜6s、星ごとに遅延をずらす）
  - 太陽・月：ごくゆっくり明るさが揺れる（opacity 0.85 ↔ 1、8s）
- 文字の読みやすさ：見出しの後ろの空は明るいまま（ダークは暗いまま）で、コントラスト比 4.5 以上を保つ
- ヘッダーは今の半透明の sticky のまま（背景の空が透けて見えてよい）

## 3. 資料：セクションごとの保存（ブックマーク）ボタンが左に見切れる

- **原因（Claude が確認）**：見出し・機材セクションの小さなブックマークボタン（`.bookmark-button.small`）が `position: absolute; right: 0` だが、親の `.bookmark-control` がセクションの左端にある幅の無い要素のため、ボタンが左へはみ出す（スマホで x = −13px）
- 対応：絶対配置をやめ、**各セクションの見出しの行の右端**に置く
  - 見出し（`heading` ブロック）：見出しの文字と同じ行の flex で、ボタンは `margin-left: auto`（文字が長いときは文字が折り返し、ボタンは右上に残る）
  - 機材セクション：折りたたみの見出しの行（イラスト・機材名・＋/−）の中で、＋/− の **左隣** に置く。ボタンを押しても折りたたみが開閉しないこと（ボタンは開閉ボタンの外に置く、または `stopPropagation`）
  - タップ領域 40×40px を確保し、画面の右端から 8px 以上内側
- 資料タイトルの横の大きなブックマークボタンはそのまま
