# N×S_Diving 改修仕様 v2.5 — 通知まわりの修正

DB の変更はなし。画面（フロントエンド）のみ。

## 1. マイページ「通知」：オン／オフの状態を正しく表示する

- **不具合**：「通知を有効にする」は状態に関係なく常に `.button`（紺の主ボタン）、「通知を停止する」は常に副ボタン。停止しても「有効」が紺色で目立ったまま（Claude が `src/pages/MyPage.tsx` の通知タブで確認）
- 対応：
  - この端末の購読状態を読み取る関数 `getPushState(): Promise<'on' | 'off' | 'blocked' | 'unsupported'>` を `src/lib/push.ts` に追加
    - `unsupported`：`supportsPush()` が false
    - `blocked`：`Notification.permission === 'denied'`
    - `on`：サービスワーカーの登録があり `pushManager.getSubscription()` が購読を返す
    - `off`：それ以外
  - タブを開いたとき・有効化／停止の後・タブが前面に戻ったとき（`visibilitychange`）に状態を取り直す
  - 表示：
    - 上部に **状態のバッジ**：「この端末の通知：オン」（ティールの丸＋文字）／「オフ」（灰色）／「ブロックされています」（黄色。解除方法の短い案内付き）／「この端末では使えません」
    - 操作は **2 択のセグメント**（`.chip` と同じ `aria-pressed` の見た目、または大きめのトグル）：「オン」「オフ」。**現在の状態の側だけが紺（選択中の色）**、もう一方は白地。押すと切り替え、処理中は両方を無効化して「設定中…」
  - 「テスト通知を送る」は状態が `on` のときだけ押せる（`off` のときは「通知をオンにすると送れます」と小さく表示）
  - 「ほかに N 台で通知を受け取っています」の表示は残す

## 2. マイページ「通知」：【設定の方法】ボタンと説明のパネル

- 通知タブの見出しの右（スマホでは見出しの下）に **「設定の方法」** ボタン（副ボタン、`?` のアイコン付き）
- 押すと **同じ画面の上に説明のパネル** が出る（モーダルダイアログ）
  - 背面に半透明の幕、中央（スマホでは下からせり上がるシート）にパネル、右上に **×（閉じる）**。幕のタップ・Esc でも閉じる。開いている間は背面のスクロールを止め、フォーカスをパネル内に閉じ込め、閉じたら「設定の方法」ボタンにフォーカスを戻す（`<dialog>` 要素を使ってよい）
  - 管理画面ではないので、開閉のアニメーション（フェード＋少し上に移動、240ms）あり。reduced-motion では無し
- パネルの中身：上部に **「iPhone」「Android」** のタブ（開いたとき、端末に合った方を初期表示。判定できなければ iPhone）
  - 各タブは **「① ホーム画面に登録する」「② 通知を受け取る設定」「うまくいかないとき」** の 3 見出し。手順は番号付きのリスト。ボタン名などは太字
  - **iPhone**
    - ① ホーム画面に登録する
      1. **Safari** でこのサイトを開く（LINE などのアプリ内で開いている場合は、右下などのメニューから「Safari で開く」）
      2. 画面下の **共有ボタン**（四角から上向きの矢印）を押す
      3. **「ホーム画面に追加」** を選び、右上の **「追加」** を押す
      4. ホーム画面に追加された **N×S_Diving のアイコン** から開き直す
    - ② 通知を受け取る設定
      1. ホーム画面のアイコンから開いたまま、ログインする
      2. **マイページ →「通知」** で **「オン」** を押す
      3. 「通知を送信します」と聞かれたら **「許可」**
      4. **「テスト通知を送る」** で届くか確認する
    - うまくいかないとき
      - iOS 16.4 以降が必要（設定 → 一般 → 情報 で確認できる）
      - Safari のタブのままでは通知を受け取れない。必ずホーム画面のアイコンから開く
      - 「許可しない」を押してしまったら：iPhone の **設定 → 通知 → N×S_Diving** で「通知を許可」をオン
      - 集中モード（おやすみモード等）の間は通知が表示されないことがある
  - **Android**
    - ① ホーム画面に登録する（任意）
      1. **Chrome** でこのサイトを開く（LINE などのアプリ内で開いている場合は、メニューから「Chrome で開く」）
      2. 右上の **「︙」** →  **「アプリをインストール」**（または「ホーム画面に追加」）
      3. **「インストール」** を押すと、ホーム画面に N×S_Diving のアイコンが追加される
      - 登録しなくても、Chrome のままで通知を受け取れる
    - ② 通知を受け取る設定
      1. ログインして **マイページ →「通知」** で **「オン」** を押す
      2. 「通知の送信を許可しますか？」で **「許可」**
      3. **「テスト通知を送る」** で届くか確認する
    - うまくいかないとき
      - 端末の **設定 → アプリ → Chrome → 通知** がオンになっているか
      - サイトの通知をブロックしてしまったら：Chrome でサイトを開き、アドレスバー左のアイコン → **権限 → 通知 → 許可**
      - 通知が遅れる場合は **設定 → アプリ → Chrome → バッテリー** を「制限なし」に
      - Samsung Internet・Firefox でも受け取れる
  - 最後に共通の注意：「通知の設定は端末ごとです。スマホとパソコンなど、受け取りたい端末それぞれでオンにしてください。」
- 説明文は `src/content/pushGuide.ts` にデータとして置く（将来の文言修正をしやすく）

## 3. ヘッダーのベル：パネルの見切れと、外側タップで閉じる

- **不具合の原因**（Claude が確認）：`.notification-panel` は `position: absolute; right: 0` でベルの右端にそろえているが、ベルの右にアカウントアイコンとハンバーガーがあるため、幅 340px のパネルが画面の左へはみ出す
- 対応：
  - 1024px 未満：`position: fixed; top: calc(var(--header-h) + env(safe-area-inset-top, 0px) + 6px); right: 12px; left: 12px;`（幅は画面いっぱい−24px、最大 420px で右寄せ）
  - 1024px 以上：`position: absolute` のまま、**ヘッダー右端にそろえる**か、`right` をベルの位置から計算して画面内に収める（`getBoundingClientRect()` で右端が画面外・左端が画面外にならないよう補正）
  - パネルの右上にも小さな ×（閉じる）
- **外側をタップすると閉じる**：
  - パネルが開いている間、`document` の `pointerdown` を捕まえ、パネルとベルのボタン以外が押されたら閉じる（パネル内のリンクを押したときは移動して閉じる）
  - Esc でも閉じる。ページ移動（pathname の変化）でも閉じる
  - 背面の幕は置かない（ページは操作できるまま、外側タップで閉じるだけ）
  - 閉じたらフォーカスをベルに戻す（キーボード操作時）
- ドロワー（ハンバーガーメニュー）を開いたら、ベルのパネルは閉じる（逆も同じ）
